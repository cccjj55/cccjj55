I'm **Zeyi Chen** (陈泽一), a first-year M.Sc. student in Mechanical Engineering at **Zhejiang University**, working on robot systems and simulation. My focus is narrow: **making robot numbers reproducible** — Nav2-based navigation stacks, mission state machines with explicit retry and timeout budgets, and benchmark tables that are generated by scripts instead of typed by hand. I maintain [ros2-warehouse-amr](https://github.com/cccjj55/ros2-warehouse-amr), a ROS 2 Humble warehouse AMR stack with 24 unit tests and CI that builds, expands xacro and parses every launch file; I'm currently building a 1 kHz realtime control loop with measured jitter, and a simulation throughput–accuracy Pareto sweep on MuJoCo/MJX. Details in [PROJECTS.md](PROJECTS.md).

Before ZJU, I received my B.Eng. from **Central South University** (交通设备与控制工程), where I worked on multiphysics simulation and experiment validation — three Q1 papers in *Int. J. Hydrogen Energy* and *Renewable Energy* (one first-author) and two granted utility patents. That is where the habit came from: build the model, sweep the parameters, measure the gap, and report the gap honestly.
